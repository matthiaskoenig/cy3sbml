# distrib support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read and display the SBML `distrib` package (version 1): uncertainties as node/edge columns and in the info panel, with the JSBML fixes this needs.

**Architecture:** Two JSBML fixes on a fork branch (`distrib-fixes`, merged into the fork branch `cy3sbml` that cy3sbml pins). In cy3sbml a new `PackageReader` (`DistribReader`) writes a summary column per element, using a pure formatter (`DistribSummary`); the info panel renders an uncertainty table (`UncertaintyHtml`). Test models are written and validated with libSBML.

**Tech Stack:** Java 17, JSBML (fork), Cytoscape 3 API, JUnit 6, Python (uv, `python-libsbml-experimental`).

**Spec:** `superpowers/specs/2026-09-29-distrib-design.md`

## Global Constraints

- Distrib version 1 (final specification) only; the UncertML draft is not supported.
- Uncertainties in the network: columns only (`distrib_uncertainty` String, `distrib_uncertaintyCount` Integer), no new nodes or edges.
- JSBML jars are changed only with `scripts/update_jsbml.py`, never by hand.
- No new warnings in `./mvnw -B -q verify`; Spotless (`./mvnw -q spotless:apply`) and the `lint` profile pass.
- Never use the em dash character; no agent attribution in commits, PRs, code or docs.
- Do not hand-edit `docs/release-notes.md` or `site/`.

## Review Focus

1. A model without distrib: no distrib columns are created, the document is not changed (no `listOfUncertainties` created as a side effect of reading). Test in Task 5.
2. A species reference with an uncertainty but no metaId/id: the uncertainty is written on its reactant/product edge. Test in Task 4/5.
3. An uncertainty parameter with neither value nor var (e.g. only a `definitionURL`) and a span with only one bound set: summary and HTML do not throw (`getVar()` throws when unset). Test in Task 3 and 6.
4. A `var` that references an id that does not exist: the info panel shows the id without a link, no exception. Test in Task 6.
5. The flattened comp model and model definitions run through the same readers: a comp model with uncertainties does not fail. Covered by the reader running in `SBMLReaderTask` for all `ModelSource`s; checked in the manual Cytoscape step (Task 9).

```java
   * The ids of the distrib elements (DistribBase) are not in the SId namespace of the
```

```java
  /** The prefix of the definition URLs of the distribution functions of distrib. */
  private static final String DISTRIB_CSYMBOL_PREFIX = "http://www.sbml.org/sbml/symbols/distrib/";

  /** A csymbol of a distribution function of the distrib package, if the package is enabled. */
  private static boolean isDistribCsymbol(ValidationContext ctx, ASTNode node) {
    return node.getType() == ASTNode.Type.FUNCTION_CSYMBOL
        && node.isSetDefinitionURL()
        && node.getDefinitionURL().startsWith(DISTRIB_CSYMBOL_PREFIX)
        && ctx.getPackageVersion("distrib") != null;
  }
```
