# fbc v3 (#461) and javadoc (#460) implementation plan

Spec: `superpowers/specs/2026-09-29-fbc-v3-design.md`.

## Task 1: javadoc (#460), cy3sbml branch `fbc-v3-javadoc`

1. `maven-javadoc-plugin` 3.12.0 in `pom.xml` (quiet, doclint `all,-missing`,
   `failOnWarnings`), profile `javadoc` with the `jar` goal.
2. Fix the doclint errors in `SBMLManager`, `SBMLUtil`, `SBaseHTMLFactory`.
3. `ci.yml` and `release.yml` build with `-Pjavadoc`; checksums and upload of the javadoc
   jar.
4. Docs: `release.md`, `building.md`, `CLAUDE.md`.
5. Verify: `JAVA_HOME=<full JDK 17> ./mvnw -B -q -Pjavadoc verify`, jar exists.

## Task 2: test model (cy3sbml)

1. `tools/pycysbml/fbc_v3_models.py` (python-libsbml-experimental), writes
   `src/test/resources/models/fbc/fbc_v3_example_L3V1_fbcV3.xml`; validate with libSBML (no
   errors).

## Task 3: JSBML fbc v3 (fork, branch `fbc-v3` from `origin/master`)

1. Namespace constants, `getNamespaceURI`, `getNamespaceFor`, version checks `>= 2`.
2. `FBCVariableType`, `FluxObjective.variableType`.
3. `UserDefinedConstraint`, `UserDefinedConstraintComponent`, `FBCModelPlugin` list,
   `FBCParser` read/write.
4. `KeyValuePair`, `KeyValuePairs` (annotation view).
5. Tests: read the libSBML model (all values), write/read round trip equal, write output
   read back by libSBML without errors, key-value pairs get/set, offline validation without
   fbc errors, v2 models unchanged.
6. Branch `comp-fbc-v3-flattening` from `comp-distrib-flattening`: the SIdRef attributes,
   test with a submodel with a user defined constraint.
7. Merge both into `cy3sbml`, push the branches to the fork.

## Task 4: cy3sbml reading

1. Re-pin JSBML (`scripts/update_jsbml.py --repository <fork> <sha>`).
2. `SBML`: node type, interactions, columns; kinetic node/edge type lists.
3. `FbcReader`: constraints, edges, objective variable type columns.
4. Styles: `StyleInfo`, `StyleInfo_cy3sbml`, `StyleInfo_cy3sbmlDark`; regenerate the
   style files.
5. Info panel: `SBMLUtil` maps for the constraint and component, `KeyValuePairHtml`,
   non-RDF annotation without the key-value pairs.
6. Tests: `FbcReaderTest` (v3 model: nodes, edges, columns, v2 unchanged), info panel
   tests, golden snapshot for the v3 model (regenerate, review diff: only the new model).
7. Docs: `CLAUDE.md` project line, user guide fbc section, release notes of the next
   version.

## Task 5: finish

`./mvnw -B -q verify`, `spotless:apply`, lint profile with JDK 21+, docs build
warning-free; pull request to `develop` closing #460 and #461.
