# Release notes for cy3sbml-v0.9.1
![cy3sbml logo](https://github.com/matthiaskoenig/cy3sbml/raw/develop/docs/images/logo100.png)

We are pleased to release a new version of cy3sbml.

## Highlights

- A dependency maintenance release for Cytoscape 3.10 and Java 17, with updated
  runtime libraries, build tools, Python helpers and documentation tooling.

## Dependencies

- Jackson Databind is updated to `2.22.4` and Logback to `1.6.6`.
- The JavaFX compile and test dependencies are updated to `17.0.21`. Cytoscape
  continues to provide JavaFX at runtime.
- The Python helpers and examples have refreshed dependency locks, including
  Antimony, pymetadata, certifi, Pydantic, NumPy, pandas and python-dateutil.

## Developer and build

- Maven Surefire and Failsafe are updated to `3.6.1`, JaCoCo to `0.8.16`, Maven
  Enforcer to `3.7.0`, Spotless to `3.10.4` and Error Prone to `2.51.0`.
- Python checks use ruff `0.17.3` and ty `0.0.95`.
- Documentation builds use Zensical `0.0.73`. GitHub Actions use updated versions
  of checkout, setup-java, setup-uv, upload-artifact and download-artifact.
- The warning assertions in the import tests count only warnings from the test's
  own thread, avoiding failures caused by unrelated background work.
- Continuous integration avoids duplicate runs for feature branches, caches Python
  interpreters and checks dependency updates monthly.
- Obsolete internal design documents are removed from the repository.
