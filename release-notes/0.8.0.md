## Developer and build

- The GitHub release has the javadoc jar `cy3sbml-<version>-javadoc.jar` with its
  checksums next to the app jar. The javadoc builds without errors, and CI builds it with
  the Maven profile `javadoc`, which checks it with doclint
  ([#460](https://github.com/matthiaskoenig/cy3sbml/issues/460)).
