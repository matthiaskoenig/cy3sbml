# Release notes for cy3sbml-v0.9.2
![cy3sbml logo](https://github.com/matthiaskoenig/cy3sbml/raw/develop/docs/images/logo100.png)

We are pleased to release a new version of cy3sbml.

## Highlights

- The `cy3sbml` Python package is available on PyPI for Python 3.11 and later.
- Updated dependencies and build tools, including security fixes in the
  documentation tooling and test dependencies.

## New and improved

- The [`cy3sbml` Python package](https://pypi.org/project/cy3sbml/) imports and
  visualizes SBML and Antimony models,
  applies layouts and annotations, exports images, and calls the app's
  automation commands through py4cytoscape.
- The README, Python package guide and documentation show PyPI and supported
  Python version badges.

## Dependencies

- Jackson Databind is updated to `2.23.0` and Logback to `1.6.8`.
- The Python examples use pandas `3.1.1`, and the model preparation tools use
  pymetadata `0.9.0`.
- Vulnerable Guava versions brought in by the Cytoscape test implementations
  are replaced with Guava `33.8.0-jre`. Guava is only used in tests.

## Developer and build

- The Maven Wrapper uses Maven `3.10.2`, Spotless is updated to `3.12.0` and
  Error Prone to `2.53.0`.
- Python checks use ruff `0.17.6` and ty `0.0.110`, with refreshed dependency locks.
- Documentation builds use Zensical `0.1.3`, which includes security fixes.
- GitHub Actions use setup-java `6.3.0` and setup-uv `10.4.0`.
