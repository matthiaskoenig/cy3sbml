# Release notes for cy3sbml-v0.5.1
![cy3sbml logo](https://github.com/matthiaskoenig/cy3sbml/raw/develop/docs/images/logo100.png)

We are pleased to release a new version of cy3sbml including the 
following changes:
- updated model examples with comp submodels and QualTab example
- updated dependencies (#395)
- removed unnecessary dependencies
- fixed logging warnings (#390)
- the public node and edge type constants in `org.cy3sbml.SBML` (`coreNodeTypes`,
  `coreEdgeTypes`, `kineticNodeTypes`, `kineticEdgeTypes`) changed from `String[]` to
  unmodifiable `List<String>`

Your cy3sbml team
