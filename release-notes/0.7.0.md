# Release notes for cy3sbml-v0.7.0
![cy3sbml logo](https://github.com/matthiaskoenig/cy3sbml/raw/develop/docs/images/logo100.png)

We are pleased to release a new version of cy3sbml.

## Highlights

- Support of the SBML package `distrib` (distributions) version 1: the uncertainties of
  the SBML elements are shown in the columns `distrib_uncertainty` and
  `distrib_uncertaintyCount` and in the info panel, with links from a `var` to the
  referenced element ([#281](https://github.com/matthiaskoenig/cy3sbml/issues/281)).

## New and improved

- Import of COMBINE archives (OMEX): the master SBML models of an archive (all SBML models
  if none is master) are imported, with the SBML files they reference read from the
  archive. The info panel of the document shows the archive with its metadata and files
  ([#116](https://github.com/matthiaskoenig/cy3sbml/issues/116)).

## Fixed

- The reactant, product and modifier edges have the id and name of their species
  reference in the columns `sbml id` and `shared name`.

## Changed and removed

## Developer and build

- JSBML is pinned to a fork commit with the distrib fixes: distrib ids are not registered
  in the SId namespace, the type `coeffientOfVariation` written by libSBML is read, copies
  of uncertainties keep their parameters, the flattening of comp models renames the distrib
  references, and the offline validation accepts the distribution functions in math
  ([#281](https://github.com/matthiaskoenig/cy3sbml/issues/281)).
- The distrib test models are written and validated with libSBML
  (`tools/pycysbml/distrib_models.py`, `python-libsbml-experimental`).
